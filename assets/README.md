[logo.png](logo.png) is the original transparent app mark: a violet note flowing into a teal checkmark. It is used in the repository README. [icon.svg](icon.svg) is a simplified vector version; [icon.png](icon.png) is a small raster export for other uses.

- Generation: built-in image generation tool; no CLI fallback

## Generation prompt

Use case: logo-brand. Asset type: final standalone app icon for an open-source plugin that turns Obsidian daily-note checkboxes into Super Productivity tasks. Create one original, polished, minimal geometric logo: a folded note or page whose continuous ribbon becomes a confident rising checkmark, conveying notes becoming action and forward progress. A distinctive compact silhouette, balanced negative space, premium modern developer-tool aesthetic. Rich violet and vivid teal as two restrained accent colors, with crisp edges and subtly rounded corners. Flat vector-like design, no 3D, no shadows, no gradients, no texture. Center a single mark with generous even padding on a genuinely transparent background (preserve alpha). Square composition, legible at small app-icon sizes and on both light and dark backgrounds. No text, no lettering, no wordmark, no mockup, no watermark, no existing brand symbols; do not copy either Obsidian's crystal icon or Super Productivity's logo.

The output was visually reviewed and its transparent alpha channel verified. The master image is preserved; the README controls its display size. The small PNG is a mechanical downscale using System.Drawing with bicubic interpolation. The SVG is a simplified code-native version of the note/checkmark design with flat colors.
