# Notes to Actions 1.0.0

The first release turns unchecked tasks in today's Obsidian daily note into Super Productivity tasks, using its built-in local REST API.

## Features

- Select your daily-note folder and filename format.
- Import on demand from the command palette, ribbon, or plugin settings.
- Match hashtags to existing tags; keep unmatched hashtags as task-title text.
- Skip earlier imports, including completed and archived tasks, and resume interrupted imports.
- Open the source daily note from a backlink in each imported task.
- Install one Obsidian plugin; no Super Productivity companion is required.

## Requirements and installation

Requires Obsidian desktop **1.7.7+** and Super Productivity desktop **19.0.1+** on the same computer.

1. Download **obsidian-super-productivity.zip** from this release.
2. Extract its `super-productivity` folder into your vault's `.obsidian/plugins/` directory, restart Obsidian, and enable **Notes to Actions**.
3. In Super Productivity, enable the local REST API under **Settings → General → Misc Settings** and copy its access token into the Obsidian plugin settings.
4. Set the daily-note path, test the connection, and run **Sync today's tasks to Super Productivity**.

See the [installation guide with screenshots](https://github.com/mostafaelaraby/obsidian-notes-to-actions#step-by-step-installation) for details. The separate `main.js`, `manifest.json`, and `styles.css` assets support Obsidian's plugin installer. GitHub's automatic source archives require building first.

This is a desktop-only, on-demand import. It does not update existing tasks or write completion status back to Obsidian. The plugin is not yet listed in the community directory.

## Verification

All 60 automated tests and packaging checks passed on Windows and Linux before release preparation. Native desktop testing verified connection, task import, tag matching, and duplicate prevention.
